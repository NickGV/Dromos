# Interface language: English first, Spanish optional

Objective: all interface copy in English by default, with a switch to show it in Spanish.
Branch: `feat/i18n` · Delivery: `ask-on-risk` → `feature-branch-chain` (units on the branch, one merge to `main` at the end) · Runner: `npm test` (Vitest), plus `npm run lint` and `npm run build`.

## Specs

- **S1** — Language: "deberiamos poner todo en ingles, pero con la posibilidad de verlo tambien en espanorl". English is the default.
- **S2** — The switch: "quizas si hacer lo de ingles y poder hacer el switch ya que luego nos puede hacer mas dificil o mas demorado realizarlo, asi que si pienso que sea mejor ahroa". A setting in the Dromos settings tab; Spanish keeps the copy Dromos has today, word for word.
- **S3** — Scope: only the interface copy. Data contracts stay as they are: the keys of `Character.md` (`fuerza`, `inteligencia`, `espiritu`, `disciplina`), note contents, campaign and phase names written in the vault, and the notes Dromos sends to Habitica (`Dromos · <campaign title>`).
- **S4** — Existing rules still hold: Obsidian UI strings use sentence case (`CLAUDE.md`), code, comments, tests and docs are in English.

Decisions and assumptions (mine, from the user's words; to be confirmed):
- **A1** — The language is a Dromos setting (English by default), not read from Obsidian's own language, because the user said English by default.
- **A2** — Switching applies to the open view at once, without a reload.
- **A3** — English wording of the Spanish game terms: Campañas → Campaigns, Detenida → Stalled, Quests → Quests, Enviar a Habitica → Send to Habitica, Sincronizar → Sync.
